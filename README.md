**Space Platformer**



**About the Game**

Space Platformer is a 2D platformer game made using the Godot Engine.

In this game, you control a character who must navigate through a platform and reach the goal. The player must avoid obstacles and lava along the way


**How to Play**

You can play the game online here:

https://afr465.itch.io/space-platformer

**Controls**

Movement: A&D

Jump: W


How to Run Locally

Download or clone this GitHub repository.

Install the Godot Engine.

Open Godot.

Click Import and select the project.godot file from the downloaded project folder.

Open the project and press the Play button  to run the game.
